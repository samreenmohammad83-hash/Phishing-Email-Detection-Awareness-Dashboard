# MITRE ATT&CK Mapping

At a high level, phishing is represented in the MITRE ATT&CK Enterprise knowledge base under the social-engineering/phishing family of techniques. Relevant concepts include:

- Spearphishing Attachment
- Spearphishing Link
- Spearphishing via Service

Technique IDs and exact sub-technique naming should be checked against the current MITRE ATT&CK release before inclusion in a formal report. This project intentionally avoids inventing IDs.

Mapping detections to a recognized framework helps SOC teams document what behavior a control is intended to identify.
